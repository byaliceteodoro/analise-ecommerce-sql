## 🏗️ Estrutura do Banco de Dados

**4 tabelas relacionais** modelando um e-commerce real:

| Tabela         | Descrição                          |
|----------------|------------------------------------|
| `clientes`     | Dados dos compradores (nome, cidade)|
| `produtos`     | Catálogo da loja (preço, categoria)|
| `pedidos`      | Histórico de compras (status, canal)|
| `itens_pedido` | Detalhes dos itens comprados       |

## 🚀 Como Executar

1. Acesse [SQLiteOnline](https://sqliteonline.com)
2. Cole o conteúdo do arquivo `ecommerce.sql`
3. Execute e veja os resultados!
